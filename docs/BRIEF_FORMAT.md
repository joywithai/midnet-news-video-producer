# brief.md contract

Required headings:
- `# Full News`, then `## English` and `## বাংলা অর্থ`
- `# Photo / Resource Names`
- `# Thumbnail Ideas` with exactly 3 numbered ideas
- `# Titles` with exactly 3 numbered titles
- `# Description`

The English section drives subtitles and video duration. Bengali is retained for review but not rendered by default.
